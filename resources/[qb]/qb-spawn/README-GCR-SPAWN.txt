GRAND COUNTRY ROLEPLAY - QB-SPAWN (4 PILIHAN)

Pilihan menu:
1. Airport
2. Sandy Shores
3. Paleto Bay
4. Last Location (lokasi terakhir karakter disimpan oleh QBCore)

Untuk karakter baru yang belum memiliki posisi tersimpan, Last Location
menggunakan Airport sebagai lokasi cadangan.

Lokasi rumah dan apartemen tidak ditampilkan sebagai pilihan terpisah.
Pemilihan Last Location memakai koordinat tersimpan, bukan posisi sementara
yang berubah saat melihat kamera spawn.

Pemasangan: ekstrak folder qb-spawn ke resources/[qb]/, ganti file lama
(setelah backup), lalu restart resource melalui console.
Uji terutama karakter lama dan karakter baru setelah instalasi.
